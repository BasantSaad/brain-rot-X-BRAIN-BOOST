# Memory And Learning Techniques

Tags: memory, active recall, spaced repetition, flashcards, revision, learning

Active recall is stronger than rereading. The learner should close the notes and try to answer a question, solve a problem, or explain the idea from memory. This reveals what is actually stored in memory.

Spaced repetition improves long-term retention. Review new material soon after learning, then again after a longer gap. The goal is to revisit information just before it is forgotten.

Interleaving helps when studying problem-solving subjects. Instead of practicing one type of question for a long time, mix related question types after the basics are understood. This trains the student to choose the right method, not only repeat a pattern.

A strong brain boosting routine is: learn a small section, test yourself, correct mistakes, then schedule a later review. The correction step matters because it turns errors into useful feedback.
