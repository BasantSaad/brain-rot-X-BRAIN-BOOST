# Parent Guidance For Focus Support

Tags: parent, guardian, support, summary, boundaries, coaching

Parent summaries should be supportive and trend-based. They should explain focus, sleep, check-ins, timers, and app usage without turning the system into minute-by-minute surveillance.

A good parent message uses gentle boundaries: "Let us protect bedtime" is better than "You used your phone too much." The goal is to help the child recover attention and build self-control.

Parents should look for patterns across the week. If app usage rises and sleep drops, the next step can be a calmer evening routine. If timers and check-ins improve, the parent should notice and encourage the progress.

The system should avoid shame. Brain boosting works best when the student feels guided, not watched.
